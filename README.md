# Link — Auth System

Дизайн системы авторизации Link (iOS): 31 экран + интерактивный прототип.

## Файлы

- `Link — Auth System.html` — готовая сборка: один самодостаточный файл,
  открывается в любом браузере офлайн, все экраны и все состояния внутри.
- `source/Auth System.dc.html` — исходник страницы (шаблон + логика).
- `source/support.js` — рантайм, нужен исходнику.
- `source/assets/` — логотип Link и 12 аватаров для экрана профиля.

Локально: открыть `Link — Auth System.html` двойным кликом.
Для правок — открывать `source/Auth System.dc.html` (рядом должен лежать `support.js`).

## Режимы страницы

- **Все экраны** — сетка артбордов, сгруппированных по секциям.
- **Один экран · клик** — рабочий прототип: номер → выбор канала (SMS / Telegram /
  WhatsApp / Apple / Google / passkey) → код → профиль.
